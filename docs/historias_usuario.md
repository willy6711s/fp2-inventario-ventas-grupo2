# Historias de usuario

Prioridad: Alta = imprescindible para el primer uso; Media = importante; Baja = deseable. Tipo: C = control, K = cálculo.

| ID | Historia de usuario | Tipo | Prior. |
| --- | --- | --- | --- |
| HU01 | Como administrador, quiero registrar repuestos individuales y kits para tener un catálogo ordenado | C | Alta |
| HU02 | Como vendedor, quiero buscar repuestos por número de parte o nombre para consultar precio y stock rápidamente | C | Alta |
| HU03 | Como administrador, quiero listar, modificar y dar de baja repuestos para mantener el catálogo actualizado | C | Alta |
| HU04 | Como administrador, quiero registrar proveedores para saber a quién compro cada repuesto | C | Media |
| HU05 | Como vendedor, quiero registrar y buscar clientes (RUC o DNI) para emitir el documento correcto | C | Alta |
| HU06 | Como vendedor, quiero registrar una cotización con varios repuestos y que el sistema valide el stock disponible | C | Alta |
| HU07 | Como vendedor, quiero que el sistema calcule subtotal, descuento, IGV (18 %) y total de la cotización | K | Alta |
| HU08 | Como vendedor, quiero convertir una cotización aprobada en factura o boleta según el tipo de cliente | C | Alta |
| HU09 | Como personal de almacén, quiero registrar ingresos de mercadería y ajustes de stock para mantener el inventario real | C | Alta |
| HU10 | Como administrador, quiero recibir alertas de repuestos con stock igual o menor al mínimo | C | Alta |
| HU11 | Como vendedor, quiero ver las cotizaciones pendientes y por vencer para dar seguimiento a los clientes | C | Media |
| HU12 | Como administrador, quiero calcular la comisión de cada vendedor según sus ventas del periodo | K | Media |
| HU13 | Como administrador, quiero conocer la valorización del inventario (stock × costo) | K | Media |
| HU14 | Como administrador, quiero calcular la utilidad bruta y el margen por periodo | K | Media |
| HU15 | Como administrador, quiero listar el historial de cotizaciones y ventas por fecha, cliente o vendedor | C | Media |
| HU16 | Como administrador, quiero guardar y cargar la información en archivo para no perder datos al cerrar el programa | C | Baja |
